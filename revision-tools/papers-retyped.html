Q3 — Garden-watering robot + A* theory 10 + 10 marks

  1. An artificially intelligent garden watering robot works a garden divided into 20 squares (4×5 grid). It can water one square per action and can move up, down, left, right. The task is complete when the entire garden is watered.
    1. Provide a formal description of this task as a search problem: initial state, actions, transition model, goal test, path cost.
    2. Determine the size of the branching factor and the state space.
  2. "The A* algorithm is always complete and optimal." Explain, considering admissibility and consistency. [10]
Model answer sketch
(a) Initial: robot at start cell, all 20 squares unwatered. Actions {Up, Down, Left, Right, Water}. Transition: moves change position (blocked at edges); Water marks current square. Goal test: all 20 watered. Path cost: 1 per action. Branching factor b = 5. State space = 20 × 220 = 20,971,520.
(b) A* is complete (finite branching, positive step costs). It is optimal if h is admissible — h(n) ≤ h*(n), never over-estimates (tree search) — and consistent — h(n) ≤ c(n,n') + h(n') (graph search). Consistent implies admissible. Without admissibility, A* may return a suboptimal path, so "always optimal" holds only under these conditions.

    answer
    False.
