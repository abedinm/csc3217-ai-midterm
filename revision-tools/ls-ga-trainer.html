The one idea behind all of it

Classical search (BFS, UCS, A*) returns a path. Local search doesn't care about the path — only the final state. So it keeps just the current state (or a few), looks at neighbours, and moves. Constant memory, works in huge or infinite spaces, but gives up completeness and optimality.

Your deck's phrasing: "in many problems the path to the goal is irrelevant" — 8-queens, circuit layout, job-shop scheduling, vehicle routing, portfolio management.

State-space landscape vocabulary

  • Objective function → you want the highest peak (global maximum).
  • Cost function → you want the lowest valley (global minimum). Convert between them with a minus sign.
  • Complete algorithm always finds a goal if one exists; optimal always finds the global best.

Hill climbing and its three failure modes

Steepest-ascent hill climbing loops: move to the best neighbour; stop at a peak where no neighbour is better. It keeps no search tree — only the current state and its value. It gets stuck on:

  • Local maxima — a peak lower than the global one, but every neighbour is worse.
  • Ridges — a sequence of local maxima that's hard to navigate with single moves.
  • Plateaux — a flat area where no neighbour improves, so there's no direction to go.
VariantWhat it changes
Steepest-ascentAlways takes the best neighbour.
StochasticPicks at random among the uphill moves; probability can vary with steepness. Converges slower but sometimes finds better solutions.
First-choiceGenerates successors randomly until one is better. Good when a state has thousands of successors.
Random-restart"If at first you don't succeed, try, try again." Repeats hill climbing from random starts until a goal is found. Very effective for 8-queens.

All plain hill-climbing variants are incomplete. NP-hard problems typically have exponentially many local maxima.

Simulated annealing

Hill climbing never goes downhill, so it gets stuck; a pure random walk is complete but hopeless. SA combines both. Your deck's algorithm:

if (Δ < 0) or (e^(−Δ/T) > u) then accept

  • Good move → always accept.
  • Bad move → accept with probability e^(ΔE/T). Compare against a random u.
  • High T → almost any bad move accepted (wild exploration). Low T → behaves like plain hill climbing. T is reduced over time.
  • The worse the move, the smaller the acceptance probability.

Local beam search

  • Keeps k states, not one. Starts with k random states.
  • Each step: generate all successors of all k states. If any is a goal, halt. Otherwise keep the k best from the whole pool.
  • Not the same as k parallel restarts — useful information passes between the threads, so search effort concentrates where progress is being made.
  • Stochastic beam search picks k successors at random (weighted by value) instead of the strict best k — keeps diversity.

Genetic algorithms

Your deck's definition: "a variant of stochastic beam search in which successor states are generated by combining two parent states rather than by modifying a single state."

  • Encoding — chromosome as a string (binary, value, permutation).
  • Fitness function — scores each individual. For n-queens: number of non-attacking pairs, max n(n−1)/2 = 28 for 8 queens.
  • Selection — roulette wheel: probability proportional to fitness.
  • Crossover — pick a point, swap the tails of two parents.
  • Mutation — flip a bit with small probability. This is what injects genuinely new material.
  • Survival / update — form the new population, repeat.

Continuous spaces

  • Most real environments are continuous; only first-choice hill climbing and SA cope directly, because branching factor is infinite.
  • Easiest fix: discretize the neighbourhood of each state.
  • Gradient ∇f gives magnitude and direction of steepest slope; maxima solve ∇f = 0.
  • Steepest-ascent update: x ← x + α∇f(x). If α too small → too many steps; too large → overshoots.
  • Newton–Raphson: x ← x − H⁻¹f(x) ∇f(x), where H is the Hessian of second derivatives.

Marks discipline

  • Say which direction you're optimising before you start — half the lost marks are minimisation solved as maximisation.
  • Generate successors in alphabetical order; the question says so explicitly.
  • For SA show ΔE, the probability, the comparison with u, and the verdict for every successor — including the rejected ones.
  • For GA show the fitness table, total, probability, and bins before you touch crossover.
  • State the stopping condition in words: "no neighbour is better, so it terminates here."
