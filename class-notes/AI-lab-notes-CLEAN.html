01Local Search · Simple Hill ClimbingquizLab class 1 · 10 Aug 25

Local Search

  • Operates using a single current node.
  • No backtracking.
  • Keeps a small number of nodes in memory.
  • Node search is on the surrounding nodes only.

Simple Hill Climbing

The four cases drawn in the notes: local and global optima separate, or coinciding — for maximisation and minimisation.
Margin note Moves step by step and follows the better step (the step above the current one). Marked "better option" but also "slow".

Limitations

  1. Local maxima / minima
  2. Plateau — a flat region. Note in the margin: if the surrounding values are equal (e.g. 50, 50, 50) there is no higher value to target.
  3. Ridge — a direction problem: the improving moves do not line up with the available single moves.
02Hill-Climbing Variants · Simulated Annealingquiz

Steepest Hill Climbing

  • Judges the successor values and chooses the best option (highest value).
  • Generates the successors, then takes one step — a jump to the highest value.
  • Marked: fast.

Stochastic Hill Climbing

Chooses at random among the uphill moves (the amount of "up hill" varies).

Random Restart Hill Climbing

Until you reach the global maxima, try and try again randomly — restart again from where it stopped.

First Choice

Left blank in the notes — the heading is written with no content under it. (For reference: first-choice generates successors at random until one is better than the current state.)

Simulated Annealing

Noted as: complete with efficiency.

Formula written in the notes
e^(dE / T) dE = energy (change in evaluation) T = temperature / time evaluation = heuristic value

Successors of S (E = 100), with T = 10 and a random value for each: A(95, 0.65), B(105, 0.8), C(90, 0.5), D(85, 0.2). A bad move is accepted only if the random value is less than the calculated probability.

For A

dE = E(A) - E(S) = 95 - 100 = -5 e^(dE/T) = e^(-5/10) = e^(-0.5) = 0.607 0.65 > 0.607 [X] rejected (compare against the probability value)

For B

For C  [current state now updated to B]

For D

n-Queens Problem

  • For n = 8: one queen per column, and no queen may attack another.
  • An attack counts both directions — there is no "backward only".
The formula
max non-attacking pairs = n(n-1)/2 = 8(8-1)/2 = 28 Non-attacking = fitness 28 - 4 attacks = 24 (fitness)

A chromosome such as 2 4 7 4 8 5 5 2 is read as: column 1 has its queen in row 2, and so on.

09n-Queens — counting the attacksquiz

Method

  • Count on the row only: look for the same row value.
  • Then take the given row value and check it with a steady increment and decrement — that catches the diagonals.
  • Every hit adds to the attack count.

Queen problem in CSP

V -> Q1, Q2, Q3, Q4 D -> R1, R2, R3, R4 C -> queens cannot attack each other
Queens placed one per column, as drawn on the page.
(i) R1 != R2 (ii) C1 != C2 (iii) |R1 - R2| != |C1 - C2|

The note beside (iii): if the two differences come out equal, the queens lie on the same diagonal — that is the attack.

16Bayesian Network · Naive Bayes19 Aug

Naive Bayes Theorem

P(A|B) = P(B|A) . P(A) / P(B)

The page first writes P(B|A) and crosses it out before settling on the form above.

Example 1

P(J, A, -E) = P(J|A) . P(A|-E) . P(-E) = 0.5 x 0.2 x 0.7 = 0.07

And the conditional form, using the chain rule:

P(J | A, -E) = P(J, A, -E) / P(A, -E)

Margin note: if an event has already occurred, its probability is taken as 1.

Example 2

P(A | J, -M) = P(A, J, -M) / P(J, -M) = [ P(A|-E) x P(J|A) x P(-M|A) ] / [ P(J|A) x P(-M|A) ] = (0.2 x 0.5 x 0.4) / (0.5 x 0.4) = 0.2
17Bayesian inference — full worked query

Query

P(-A | J, -M) = P(-A, J, -M) / P(J, -M)

Both parts are expanded by summing the hidden variables out. The numerator sums over E; the denominator sums over E and A, giving four terms:

numerator = sum over E of P(E) . P(-A|E) . P(J|-A) . P(-M|-A) denominator = sum over E, A of P(E) . P(A|E) . P(J|A) . P(-M|A) (four combinations: +E/-E crossed with +A/-A)

Numbers substituted

numerator = {0.3 x 0.8 x 0.5 x 0.6} + {0.7 x 0.82 x 0.5 x 0.6} denominator = {0.3 x 0.2 x 0.5 x 0.4} + {0.7 x 0.2 x 0.5 x 0.6} + {0.7 x 0.8 x 0.5 x 0.4} + {0.3 x 0.8 x 0.5 x 0.6}
